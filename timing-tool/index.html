Options go after a ; — e.g. ; label="V_{DD}" range=0:3.6 unit=V color=#d9480f h=90 hide. For span: row=SIG. Comments start with #.

Point lists

analog VDD = 0:0 1:0 3:3.3@rc 6:3.3 8:0@s
digital en = 0:0 2:1 5:x 6:z 7:0
bus mode  = 0:OFF 2:INIT 4:"RUN A" 8:x

Analog segment shape goes on the end point: @lin (default), @rc or @rc0.3 (RC with τ), @s (smooth S), @step. Two points at the same time make a vertical jump. Digital values: 0 1 x z.
